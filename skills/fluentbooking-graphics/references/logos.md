# Logos and marks

**The rule:** a graphic shows only official mark files. Never draw, retype, trace or approximate a logo or an icon, and never put a typed product name next to an icon as a stand-in logo. If a graphic needs a mark that is not in this folder, stop and ask the user for the file before building.

## FluentBooking (official, Brand Assets "Updated Logo 2025")
Files in `assets/brand/`, used through `brand_logo()` / `lockup()` (logo) and `brand()` (icon) in `kit.py`:

| Variant key | File | Use |
|---|---|---|
| `logo` | fluentbooking_primary_logo.svg | Default logo on every light or pastel ground (blue icon, #2C2C2C wordmark) |
| `logo-secondary` | fluentbooking_secondary_logo.svg | Blue icon with a white wordmark: only on a photo or image where white text is legible. FluentBooking graphics use no dark grounds, so this is rarely needed |
| `logo-dark` / `logo-light` | fluentbooking_monotone_dark_logo.svg / _light_logo.svg | Single-colour black or white, for one-colour placements only |
| `icon` | fluentbooking_primary_icon.svg | The icon alone, #2653C7 (brand tile, small placements) |
| `icon-secondary`, `icon-dark`, `icon-light` | matching icon files | As above for the icon |

The logo keeps its own proportions (318×59); set its height only. Keep clear space of at least the icon's width around it.

## Other marks
- `assets/logos/`: Fluent family marks (FluentCRM, Fluent Forms, Fluent Boards, FluentCart, FluentSMTP) plus WooCommerce and WordPress, copied from the FluentCRM graphics system. **Confirm these are the Updated Logo 2025 versions** before using them in published work; if in doubt, ask the user for the current files. Show them as small tiles at their own colours.
- **Not bundled:** Google Calendar, Google Meet, Outlook, MS Teams, Apple Calendar, Nextcloud, Zoom, Stripe, PayPal, Twilio, WhatsApp. A graphic that needs one of these marks waits until the user supplies the official file; in the meantime show the name as text only, never a drawn mark.
